Zelda: Ocarina of Time / low-resolution N64 carton

Original interpretation generated with built-in ImageGen from the supplied
front/back references. generation_prompt.txt preserves the prompt.
generated_panels.png retains the full-resolution generated source.

Run build_model.py with Python, Pillow and NumPy to export the model, texture,
preview images and viewer. Only packing/downsampling is procedural.
12 triangles, 8 unique positions, one 128x128 PNG atlas with a 32-color palette.
Front and back are 64x48 pixels; use nearest-neighbor filtering.
Dimensions: 0.180 x 0.135 x 0.028 metres. +Y up, +Z front, bottom-center origin.

Runtime files live in assets/bb.ocarina-of-time/. No ROM is included.
No catalog entry is registered yet: a player-supplied ROM must be identified
before adding its recognition hashes and metadata to catalog.json.
The pack builder includes these prepared assets without enabling a game entry.
